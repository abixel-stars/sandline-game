SANDLINE — a three.js tactical FPS: Yard 9 desert-industrial map, Jackals vs Wardens 4v4, plant/defuse the charge, buy menu, bots, with a lobby, start screen and agent preview. Playable on desktop Chrome (mouse + keyboard) and mobile Chrome (touch controls).

## Run it

```sh
python3 -m http.server 8000 --directory game
```

Then open http://localhost:8000 in a browser.
